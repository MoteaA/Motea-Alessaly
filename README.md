# Motea Alessaly — Personal Portfolio

A responsive, static personal website with no external libraries, trackers, or contact-form data collection.

## Included
- `index.html` — all page content and SEO metadata
- `styles.css` — responsive design
- `script.js` — mobile navigation and current copyright year

## Preview locally
Open `index.html` in a browser. For a more realistic local server, run `python -m http.server 8000` in this folder, then visit `http://localhost:8000`.

## Publish free with GitHub Pages
1. Have a parent/guardian help with any account or public publishing decisions if needed.
2. Create a GitHub repository named `motea-portfolio` and upload the three website files.
3. In repository **Settings → Pages**, choose deployment from the `main` branch and root folder.
4. Wait for the published URL shown in Pages settings. It will usually look like `https://YOUR-USERNAME.github.io/motea-portfolio/`.
5. Open the URL on a phone and computer to test it.

Alternative: Netlify or Cloudflare Pages can host static files on a free tier. Check their current age, account, and terms requirements before creating an account.

## Google indexing
- Publish the site first.
- Use Google Search Console to add the published URL and request indexing. Indexing and search snippets are not guaranteed.
- Keep the title and description in `index.html` accurate.
- A custom domain is optional; do not buy one until you are happy with the site.

## Privacy and credibility
- The site publishes only the name and state-level location you selected. It has no home address, school name, phone number, email, or exact workplace location.
- Because the owner is under 18, involve a parent/guardian before publishing a real-name profile or setting up hosting accounts.
- The award wording is cautious because its exact details are not yet confirmed.
- Mono Note is labeled as in development.
- The press-style quote is explicitly satirical.
- No login is built into this static website. A private editor login would require a separate CMS or hosting feature; do not put passwords in HTML or JavaScript. For a simple site, edit the files locally and upload the updates.
- If adding photos later, use images you have permission to publish and avoid exposing school logos, addresses, or identifying background details.

## Editing
Edit the wording in `index.html`. Change colors and layout in `styles.css`. No build step is required.
